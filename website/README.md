# Chkela Marketing Website

React marketing site for [chkela.com](https://chkela.com/).

## Stack

- React 19 + TypeScript
- Vite
- React Router

## Run locally

```bash
cd website
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

## Pages

| Route | Purpose |
|-------|---------|
| `/` | Home — hero, features, proof, download CTA |
| `/about` | Mission and contact |

Store links and contact details live in `src/content.ts`.
